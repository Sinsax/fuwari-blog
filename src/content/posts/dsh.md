# 心路历程
使用deepseek较多，所以试了很多harness

## opencode
:::tip
**值得一用**
:::

### 使用体验
一开始vobe coding的时候就用的这个，甚至opencode go套餐我都续了半年左右

之后也是被狠狠背刺了，好感略低

在deepseekv4刚出时，因为dsh独有的思维链启动，所以弃用了

这家的api信用有待考察

至于harness还是没有什么问题，基础的操作十分傻瓜

plan+build，基本上涵盖了很多操作，而且tab切换很方便

## minimax code
:::tip
**值得一用**
:::
### 使用体验
整体结构使用感受都是上乘的一个软件

甚至还有原生的远端控制手机扫一下就好而且不用会员😭(有泄露信息的风险)

本来真的想扎根了，可惜他的缓存命中和轮询逻辑有问题

导致运行任务会很慢而且费钱

>还有一个致命问题：
>
>如果你的程序需要涉及到密钥密码之类的敏感内容
>
>他会直接退回无法进行任务

---
## kimi code
:::tip
**值得一用**
:::
### 使用体验
其实没咋用，只是简单跑了一下任务

使用上没有太大问题，缓存·使用·界面都是很不错

跟minimax差不多都让人很舒服

- 有几个毒点
    - 对于一些中转站的api可能会无法正常使用(因为特有的信息头问题)
    - work code 功能混乱，我始终还是没找到连接手机的功能在哪


---
## deepseek-harness
:::tip
**饺子醋**
:::
### 使用体验
其实本来就是dsh webui的重度使用者，但是我的使用习惯不支持我这样

断断续续还是转了回来，原因还是官方泄露的[桌面版安装包 0.17.0 rc2](https://download.deepseek.com/dsh-desk/bin/win-x64/deepseek-harness-0.1.7-rc.2-win-x64.exe)

总算是来了桌面版，之前使用webui还是有点麻烦了

其实废话一堆，最后使用还是用官方适配的harness效果最好

但是dsh的扩展和开放水平还是比某些小气企业好不少

当前插件安装也方便了很多

推荐插件网站[dsh.so](https://www.dsh.so/zh/)
- 提示音
    - dsh-notify-me 
- 手机远端连接
    - dsh-pocket
- api使用量
    - dsh-usage-statistics-panel
